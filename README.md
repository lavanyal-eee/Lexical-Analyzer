# Lexical Analyzer Using C

## Project Overview
This project implements a Lexical Analyzer using the C programming language. It is designed to identify tokens in a subset of the C programming language.

## Features
- Identifies C keywords.
- Identifies identifiers.
- Recognizes integer numbers.
- Identifies operators such as `+`, `-`, `*`, `/`, `=`, `<`, and `>`.
- Identifies special symbols such as `;`, `,`, `(`, `)`, `{`, and `}`.

## Technologies Used
- C Programming
- Standard Input/Output
- String Handling
- Character Classification (`ctype.h`)
